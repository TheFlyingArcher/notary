## Load timing

PBES2 key load at 600,000 iterations: **275 ms per load** (Windows 11 guest on Apple M4 Pro, .NET 10, managed BouncyCastle). A Raspberry Pi will be slower, probably by 3-6x (estimate, not measured), so roughly 1-1.5 s per key load when issuing certificates or building a CRL. The iteration count is the `PbkdfIterationCount` constant and the reader honors whatever count is stored, so lowering it later does not strand existing keys. Worth measuring on the target hardware during UAT.
