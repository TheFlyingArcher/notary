# Implementation Walkthrough: Validate NOTARY_APP_KEY at startup

## Summary

The application now refuses to start unless `NOTARY_APP_KEY` is set to at least 16 characters. `NotaryConfiguration.Validate()` (already called from `Program.cs` before the container is built) throws an `InvalidOperationException` that names the setting and the minimum and never includes the value.

## Structure Overview

One new public constant, `NotaryConfiguration.MinimumApplicationKeyLength` (16), and one check at the top of `Validate()`.

## Key Implementation Details

### 1. What is rejected

Null, empty, whitespace-only, or fewer than 16 characters. The length counts characters of the raw value; whitespace-only values are rejected even when long.

### 2. Why it matters

Before the encryption fix, a missing key silently produced plaintext keys. The writer in `AsymmetricKeyService` already throws on an empty passphrase; this check turns that into a clear startup error instead of a failure on the first certificate issued.
