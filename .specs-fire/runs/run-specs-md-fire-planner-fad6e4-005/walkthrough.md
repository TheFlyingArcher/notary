## Key Implementation Details

### 1. Affected versions come from git

Plaintext storage began with commit `f9aadd0` (2026-06-22), first contained in tag `v1.1.37`; the latest tag is `v1.1.45`. Releases before `v1.1.37` stored keys with SHA-1/3DES encryption, which is weak but real encryption, and the migration upgrades those too.

### 2. Rotation advice

The page tells operators that encrypting keys now does not undo earlier exposure, and that a CA key that may have been seen should be treated as compromised: replace it, reissue and revoke what it signed.
