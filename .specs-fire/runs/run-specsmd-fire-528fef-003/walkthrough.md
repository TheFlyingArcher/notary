# Implementation Walkthrough: CA validity dropdown

## Summary

The Create CA page's free-text "CA Validity" field is now a dropdown of standard periods. With no parent it offers the root list; with a parent it offers the intermediate list, and any period that would outlive the parent is disabled with a reason. The recommended period is preselected.

## Structure Overview

The page asks `ValidityPolicy.Evaluate` for options each render, passing the role (root when no parent is selected, otherwise intermediate) and the selected parent CA's `NotAfter`. `RefreshValidity()` keeps the view model's `SelectedPeriod` consistent with those options and runs after the parent changes and on page load. Submit computes `NotAfter` from the selected period.

## Key Implementation Details

### 1. Selection rules

`RefreshValidity()` keeps the current choice if it is still allowed; otherwise it picks the recommended period if allowed, otherwise the longest allowed one, otherwise none (the select is disabled with an explanatory helper message and the Required rule blocks submit).

### 2. Display

Closed select shows the plain label ("60 months (5 years)"). Open list items add "(recommended)" and, for disabled items, " - Exceeds issuer expiry (yyyy-MM-dd)".
