# Project Constitution

> Universal policies that apply to ALL code in this project.

## Git Workflow

- **Commit Style**: Short imperative summary, optional PR number suffix (e.g. `Complete certificate revocation with RFC 5280 CRLs (#28)`)
- **Branch Strategy**: Feature branches merged via pull request
- **Main Branch**: main is always deployable

## Code Review

- All changes require pull request review
- No merging to main without passing CI
- Security-sensitive changes (key handling, signing, auth) require extra scrutiny

## CI/CD

- **Platform**: GitHub Actions (`build.yml` on PRs, `publish.yml`)
- All PRs must pass restore, build and test
- Docker cannot run locally; container changes are verified via `dotnet build`/`publish` and CI image builds

## Security Policies

- **No secrets in code** — use environment variables or secret management
- Private keys and passwords never logged or committed
- Dependencies from trusted sources (NuGet)

## Documentation

- README kept current with setup instructions
- Plans and design notes live in `docs/plan/`
- Breaking changes require migration notes
