# Testing Standards

## Framework

- **Framework**: NUnit 4 with NUnit3TestAdapter
- **Mocking**: Moq
- **Coverage**: coverlet.collector
- **Location**: `src/test/` (project `Notary.Test`), files named `{Type}Test.cs`

## Running Tests

```bash
# All tests
dotnet test --logger "console;verbosity=detailed"

# Test project only (as CI does)
dotnet test ./src/test/

# With coverage
dotnet test --collect:"XPlat Code Coverage"

# Single class
dotnet test --filter "FullyQualifiedName~CertificateRevokeServiceTest"
```

## Guidelines

- Unit-test services with mocked repositories; assert on `Result<T>` outcomes rather than exceptions
- Cover critical paths: certificate issuance, signing, revocation, CRL generation, DN validation, configuration
- Test names describe behavior (e.g. `Revoke_UnknownSerial_ReturnsFailure`)
- Generate test keys/certs in-test; never commit real private keys
- UAT is performed by the user in Visual Studio

## CI

- `build.yml` runs restore, build (Release) and `dotnet test ./src/test/` on every PR to main
