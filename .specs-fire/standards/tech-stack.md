# Tech Stack

## Overview

PKI application (certificate authorities, certificates, revocation/CRLs) for a Raspberry Pi server farm. API plus Blazor web UI, orchestrated locally with .NET Aspire.

## Core Technologies

- **Language**: C# (.NET 10, `net10.0`)
- **Framework**: ASP.NET Core with Blazor (web project uses `Microsoft.NET.Sdk.Web`)
- **UI**: MudBlazor 9.x
- **Runtime**: .NET 10

## Data Layer

- **Database**: MongoDB (`MongoDB.Driver` 3.x), Aspire MongoDB hosting for local dev
- **Mapping**: AutoMapper (`ModelMapProfile`), repository pattern in `src/library/data`

## Auth

- Auth0 (`Auth0.AspNetCore.Authentication`), Microsoft.Identity.Web, JWT bearer

## Crypto

- BouncyCastle (`BouncyCastle.NetCore`) for X.509, CRLs, key generation

## Cross-cutting

- DI: Autofac (+ DynamicProxy via Castle.Core)
- Logging: log4net
- Orchestration: .NET Aspire (`Notary.AppHost`, `Notary.ServiceDefaults`)

## Infrastructure

- Containerization: Docker (`src/Dockerfile`), built in CI only
- CI/CD: GitHub Actions

## Development Tools

- Build: `dotnet build src/Notary.sln`
- Formatter: `dotnet format`
- IDE: Visual Studio 2026 Community (used for visual confirmation and UAT)

| Tool | Minimum | Recommended |
